#+title: Personal NixOS Flake
#+description: Install this NixOS and Home Manager configuration on another PC.
#+startup: showall
#+options: toc:t

* Overview

This repo holds one NixOS system and one Home Manager user.
The shared settings live in =modules/=.
The machine settings live in =hosts/<hostname>/=.
Each PC supplies its own =hardware-configuration.nix=, its hostname, and its kernel tweaks.

** Layout

#+begin_example
.
├── flake.nix
├── flake.lock
├── README.org
├── apps/
│   └── firefox.nix
├── modules/
│   ├── system.nix      # shared NixOS settings and the user account
│   ├── packages.nix    # system packages
│   └── home.nix        # Home Manager user settings
└── hosts/
    └── zach-nixos/
        ├── default.nix                 # hostname and host-only settings
        └── hardware-configuration.nix  # disks, CPU, kernel modules
#+end_example

** The two names

=flake.nix= sets the login name in one place:

#+begin_src nix
username = "zach";
#+end_src

The config creates that account and points Home Manager at =/home/<username>=.
Change that one line to use a different login name.

A host has a name too. The host name is the key in =nixosConfigurations= and the directory under =hosts/=.
The current host is =zach-nixos=.

* Before you start

** Requirements for the target PC

- NixOS installed. If the disk is empty, do the next section first.
- 8 GB RAM or more. The package set holds large source builds. A smaller PC needs a swapfile. See Troubleshooting.
- 40 GB free disk or more. The store holds TeX Live, LibreOffice, Steam, and 32-bit graphics libraries.
- A network connection.

** Install NixOS when the disk is empty

1. Download the ISO from https://nixos.org/download.
2. Write the ISO to a USB stick and boot the target PC.
3. Install NixOS. The graphical installer is the easy path.
4. Create a user. Name it =zach=, or keep =nixos=. The config can create =zach= later.
5. Reboot into the new system, then start at Step 1 below.

The manual for the minimal ISO is at https://nixos.org/manual/nixos/stable/#sec-installation.

* Install the config on a new PC

Run every command on the target PC as your normal user.

** Step 1: enable the Nix features

Flakes and the new CLI are off by default on a blank NixOS.
Add them to the environment for this shell:

#+begin_src bash
export NIX_CONFIG="experimental-features = nix-command flakes"
#+end_src

Every =nix= and =nixos-rebuild= command in this guide needs this setting. Set it again in a new shell.

** Step 2: get the repo

#+begin_src bash
nix-shell -p git --run 'git clone https://github.com/Zachmd14/nixos-dotfiles ~/nixos-flakes'
cd ~/nixos-flakes
#+end_src

The clone path must be =$HOME/nixos-flakes=. The =nrs= alias uses that path.

If the repo is private, authenticate first. Install =gh= with =nix-shell -p gh=, then run =gh auth login=.
To skip the network, copy the repo from a PC that has it:

#+begin_src bash
rsync -av --exclude result --exclude .git ~/nixos-flakes/ <user>@<target-ip>:~/nixos-flakes/
#+end_src

** Step 3: choose the login name

Open =flake.nix= and read the =username= line.

- Keep ="zach"= to let the config create a new =zach= account. The account starts locked, so set the password in Step 10.
- Set ="nixos"= to reuse the account you logged in with. Then skip the password step.

** Step 4: create the host directory

Never overwrite =hosts/zach-nixos/hardware-configuration.nix=. That file describes the original laptop.

#+begin_src bash
HOST=$(hostname)
mkdir -p "hosts/$HOST"
#+end_src

For a different host name, set =HOST= by hand.

** Step 5: generate the hardware configuration

This command reads the disks of the target PC.

#+begin_src bash
sudo nixos-generate-config --show-hardware-config > "hosts/$HOST/hardware-configuration.nix"
#+end_src

** Step 6: write the host module

#+begin_src bash
cp hosts/zach-nixos/default.nix "hosts/$HOST/default.nix"
#+end_src

Edit =hosts/$HOST/default.nix=. The result must look like this:

#+begin_src nix
{ config, lib, pkgs, ... }:

{
  imports = [
    ./hardware-configuration.nix
  ];

  networking.hostName = "<host>";

  # Intel CPU only. Delete these two lines on an AMD PC.
  hardware.cpu.intel.updateMicrocode = lib.mkDefault config.hardware.enableRedistributableFirmware;
  boot.kernelParams = [ "i915.enable_psr=0" "i915.enable_dc=0" ];
}
#+end_src

Set =networking.hostName= to =$HOST=. Delete the last two lines on an AMD PC.

** Step 7: register the host

Open =flake.nix=. Add one line inside the =nixosConfigurations= set:

#+begin_src nix
      nixosConfigurations."<host>" = mkHost "<host>";
#+end_src

The name must match the directory under =hosts/= exactly.

** Step 8: track the new files

Nix reads only files that Git tracks. A new host stays invisible until you stage it.

#+begin_src bash
git add -A
#+end_src

** Step 9: build the system

This step finds errors and leaves the bootloader alone.

#+begin_src bash
nix-instantiate --parse "hosts/$HOST/default.nix" && echo OK
nixos-rebuild build --flake ".#$HOST" --max-jobs 1 --cores 2
#+end_src

=nix-instantiate --parse= prints =OK= on success. It prints a line number on a syntax error.
Expected time: 20 to 40 minutes, mostly downloads.

** Step 10: switch and set the password

#+begin_src bash
sudo nixos-rebuild switch --flake ".#$HOST" --max-jobs 1 --cores 2
sudo passwd "<username>"
#+end_src

The config sets no password. The account stays locked until =passwd= runs.
Run =passwd= before you log out of the old account.

** Step 11: reboot and log in

#+begin_src bash
sudo reboot
#+end_src

Log in to the =emacs= session from the display manager.
If the session fails, press =Ctrl+Alt+F2= for a console.

* After the first login

The flake does not carry these items. Do them once per PC.

** Emacs configuration

The session runs EXWM, so Emacs is the window manager.
Without =~/.config/emacs= the session shows a blank screen.
Copy the directory from the original PC:

#+begin_src bash
rsync -av ~/.config/emacs <user>@<target-ip>:~/.config/
#+end_src

** Flatpak applications

The session starts =net.sonuscape.mouseless=. Install it:

#+begin_src bash
flatpak install net.sonuscape.mouseless
#+end_src

** Factorio

The =factorio= launcher points at =~/Games/Factorio_Linux/factorio=.
Put the game there, or delete the launcher from =modules/packages.nix=.

** Secrets

=modules/home.nix= holds a plain API key. Read the Secrets section below.

* Troubleshooting

** =flake does not provide attribute nixosConfigurations."<name>"=

=nixos-rebuild --flake=.= uses the current hostname as the attribute name.
This error means the flake has no host with that name.
Add =#<host>= to the command, or register the host in =flake.nix=.

** =Path ... is not tracked by Git=

Nix reads only tracked files. Run =git add -A= in the repo, then retry.

** =experimental Nix feature 'nix-command' is disabled=

Step 1 did not run in this shell. Run the =export NIX_CONFIG= line again.

** =Out of memory: Killed process (nix)=

The build ran out of RAM. Pick one:

- Give the PC more RAM. 8 GB or more is safe.
- Add a swapfile. Append this line to =hosts/<host>/default.nix=, then switch:
  #+begin_src nix
  swapDevices = [ { device = "/var/swap"; size = 8192; } ];
  #+end_src
- Lower the build parallelism. Add =--max-jobs 1 --cores 1=.
- Remove a large source build. In =modules/packages.nix=, replace the =(mixxx.overrideAttrs ...)= block with =mixxx=. Then delete the =factorio-fhs= block and the =++ [ factorio-fhs ]= part.

** =write of ... No space left on device=

The store filled the disk. Check the free space:

#+begin_src bash
df -h /
#+end_src

Remove old generations and unneeded store paths:

#+begin_src bash
sudo nix-collect-garbage -d
sudo nix store gc
#+end_src

On a VM, the partition can be smaller than the disk. Grow it:

#+begin_src bash
lsblk
sudo growpart /dev/vda 1
sudo resize2fs /dev/vda1
#+end_src

Adjust the device names to the =lsblk= output.

** The bootloader step fails on a VM

The shared config uses =systemd-boot=, which needs UEFI.
On a BIOS VM, replace it in =hosts/<host>/default.nix=:

#+begin_src nix
boot.loader.systemd-boot.enable = false;
boot.loader.grub.enable = true;
boot.loader.grub.device = "/dev/vda";
#+end_src

** The account is locked

=passwd <username>= failed, or the login is refused.
Run the switch again, then =sudo passwd <username>=. The account has no password until then.

** The graphical session is blank

The EXWM session needs =~/.config/emacs=. Copy the directory, or pick another session at the display manager.

* Add another host later

1. Create =hosts/<new-host>/=.
2. Generate =hardware-configuration.nix= on that PC with =nixos-generate-config=.
3. Copy and edit =default.nix=. Set =networking.hostName=.
4. Add one line to =nixosConfigurations= in =flake.nix=.
5. Run =git add -A=.
6. Run =sudo nixos-rebuild switch --flake .#<new-host>=.

* Shared settings and host settings

=modules/system.nix= is shared by every host. It keeps assumptions about the original laptop:

- TLP battery thresholds.
- A backlight udev rule.
- ACPI and audio rules.

Each rule matches only devices that exist, so a desktop ignores it.
Move a setting into =hosts/<host>/default.nix= when it is wrong for another PC.

* Secrets

=modules/home.nix= holds a plain API key. The key is in the Git history.

- Rotate the key if the repo was ever public.
- Keep the repo private.
- For stronger protection, move the key to sops-nix or agenix, then delete it from =modules/home.nix=.

* Daily use

- Rebuild and switch:
  #+begin_src bash
  nrs
  #+end_src
  The alias runs =sudo nixos-rebuild switch --flake $HOME/nixos-flakes=.
- Test a change, then roll back on reboot:
  #+begin_src bash
  sudo nixos-rebuild test --flake ~/nixos-flakes
  #+end_src
- Update every input:
  #+begin_src bash
  nix flake update
  #+end_src
- Check the flake:
  #+begin_src bash
  nix flake check
  #+end_src
